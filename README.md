ترازنامه بهبودی
اپلیکیشن «ترازنامه بهبودی» با هدف کمک به ثبت، مرور و پیگیری روزانه فرایند بهبودی طراحی می‌شود.
هدف پروژه
این برنامه بر پایه ساختار فایل Excel اولیه «ترازنامه بهبودی» توسعه داده می‌شود و هدف آن تبدیل فرایند ثبت ترازنامه روزانه به یک محیط ساده، منظم و قابل استفاده در تلفن همراه است.

• ردیاب ۳۱ روزه
• گزارش و مرور

• پشتیبان‌گیری و بازیابی اطلاعات
هسته ترازنامه
هسته اصلی برنامه بر اساس ۳۷ سؤال استخراج‌شده از ساختار اصلی Excel طراحی می‌شود.
سؤالات در بخش‌های مختلف ترازنامه دسته‌بندی شده و کاربر می‌تواند پاسخ‌های روزانه خود را ثبت و بعداً مرور کند.
