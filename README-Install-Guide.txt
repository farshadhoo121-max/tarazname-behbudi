ترازنامه بهبودی - نسخه نصب‌شونده (PWA)

فایل اصلی برنامه: index.html

نکته مهم:
برای اینکه Chrome آن را به شکل «اپ» نصب کند، فایل‌ها باید از یک آدرس http/https باز شوند. باز کردن مستقیم فایل با file:// برای نصب PWA کافی نیست.

محتویات پوشه:
- index.html  ← همان tarazname-behbudi-fixed-v2.html با امکانات نصب اپ
- manifest.webmanifest ← مشخصات اپ
- sw.js ← سرویس‌ورکر برای اجرای سریع‌تر و قابلیت کش
- icon-192.png / icon-512.png ← آیکون اپ

در Chrome بعد از باز کردن آدرس اینترنتی برنامه، از منوی Chrome گزینه «Install app / نصب برنامه» را بزنید. اگر دکمه «📲 نصب برنامه» داخل برنامه ظاهر شد، همان را هم می‌توان استفاده کرد.
